# Visual Design Direction

Use a **modern AI/developer aesthetic** with a premium, clean appearance.

Preferred visual characteristics:

* Dark or dark-modern interface
* High-quality typography
* Subtle gradients
* Glassmorphism used sparingly
* Rounded cards
* Fine borders
* Soft shadows
* Minimal glowing accents
* Smooth scrolling
* Micro-interactions
* Elegant hover effects
* Responsive layouts
* Professional spacing
* Strong visual hierarchy

The website should feel like a combination of a **modern software engineer portfolio + AI developer portfolio**, rather than a generic student website.

Avoid:

* Excessive animations
* Cartoon-style graphics
* Overly bright colors
* Generic stock imagery
* Fake achievements
* Fake companies
* Fake work experience
* Invented project statistics
* Unsupported technologies
